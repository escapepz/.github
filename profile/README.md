# 👋 Welcome to eScape on PZ

We build open-source tools, libraries, and mods for **Project Zomboid** (with a primary focus on Build 42). From developer workflows and testing frameworks to interactive multiplayer gameplay mechanics, everything here is built to make Zomboid modding cleaner, faster, and more fun.

---

### 🛠️ Developer Tools & Templates
* **[pzstudio](https://github.com/escapepz/pzstudio)** — Effortlessly create, build, and sync Project Zomboid Lua mods *(TypeScript)*.
* **[pzstudio-template-project](https://github.com/escapepz/pzstudio-template-project)** & **[pzstudio-template-mod](https://github.com/escapepz/pzstudio-template-mod)** — Ready-to-use starter templates for PZStudio42.
* **[pz_translation_json_schema](https://github.com/escapepz/pz_translation_json_schema)** — JSON Schema validation for Project Zomboid translation files *(Python)*.

### 📚 Core Lua Libraries & Frameworks
* **[pz_lua_commons](https://github.com/escapepz/pz_lua_commons)** — A curated collection of reusable Lua libraries maintained for Project Zomboid modding.
* **[pz_lua_testkit](https://github.com/escapepz/pz_lua_testkit)** — Offline unit and integration testing framework for Project Zomboid B42 Lua mods.
* **[zul](https://github.com/escapepz/zul)** — A unified logging framework featuring multi-level logging, child loggers, and configurable sandbox options.

### 🎮 Featured Mods
* **[just_another_shop_mod (JASM)](https://github.com/escapepz/just_another_shop_mod)** — Turn ordinary storage crates into fully functional, interactive player storefronts in Project Zomboid Build 42.
